# Lipidomic association analyses of white matter phenotypes for ADO2

Date:
- 2026-10-23

Project:
- Metabolomic_BrainStructures_ZP
- Analysis focus: White matter lipidomic associations in ADO2, with comparison to ADO1

Project-specific configuration:
- File: ~/Documents/scripts/Metabolomic_BrainStructures_ZP/project_specific_inputs.R
- Purpose: Defines shared project paths and working directory variables used by the analysis, including `wd`.

Working directory:
- Source: `project_specific_file`
- Set by: `setwd(wd)`

Study summary:
- This analysis reads ADO2 covariate, lipidomic, and MRI phenotype data.
- It performs association analyses between lipids and white matter measures.
- It compares ADO2 results to ADO1 white matter lipid association results.
- It generates volcano plots for trait-specific association summaries.

Data processing notes
---------------------
- Lipid data from ADO2 were merged across two source tables.
- Negative lipid values were converted to NA.
- Individuals with no lipid measurements were removed.
- Metabolites with >20% missingness were filtered out.
- Metabolite IDs were harmonized between ADO1 and ADO2 before comparison.
- FDR correction was applied using the Benjamini-Hochberg method.
